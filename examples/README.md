# Примеры (синтетика)

Эти четыре страницы собраны из полностью вымышленного корпуса
(`scripts/00_make_demo.py`: три выдуманных собеседника, сгенерированные тексты,
эмо-разметка суррогатным флагом --synthetic). Никаких настоящих данных здесь нет —
открывай смело. Твои страницы будут выглядеть так же, только с твоей жизнью внутри.
