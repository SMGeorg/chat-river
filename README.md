# Chat River 🌊

**Твоя переписка Telegram — как река: интерактивные визуализации твоей жизни из твоего
собственного экспорта. Всё считается локально — ни одно сообщение не покидает твой компьютер.**

Из полного экспорта Telegram ты получаешь четыре страницы:

| Артефакт | Что показывает |
|---|---|
| **Ngram Viewer** (`out/ngram-viewer.html`) | частота любого слова в твоей речи по месяцам за все годы; рождение и смерть слов |
| **Река общения** (`out/river.html`) | с кем текла твоя переписка: русла-люди, подсветка, твои реплики из прошлого при наведении, «температура» отношений, экспорт постера |
| **Эмоциональная дуга** (`out/emo-arc.html`) | средний эмоциональный тон твоих сообщений месяц за месяцем через все годы + состав эмоций; требует опционального LLM-шага |
| **Языковой двойник Big5** (`out/big5.html`) | твой личностный тест против 10+ лет твоего реального языка: что сходится, что нет |

**Хочешь сначала посмотреть, как это выглядит?** Живые примеры из полностью
**синтетического** корпуса (вымышленные люди, сгенерированные тексты) — открывай прямо
в браузере:
[Река общения](https://smgeorg.github.io/chat-river/examples/river.html) ·
[Эмоциональная дуга](https://smgeorg.github.io/chat-river/examples/emo-arc.html) ·
[Ngram Viewer](https://smgeorg.github.io/chat-river/examples/ngram-viewer.html) ·
[Big5-двойник](https://smgeorg.github.io/chat-river/examples/big5.html).
Твои страницы будут такими же, только про тебя (и останутся у тебя на диске —
в отличие от этих примеров, никуда не выкладываются).

## Три уровня обработки — выбери свой

Первый вопрос перед запуском: что ты готов делать со своими данными. Три пакета,
от параноидального к быстрому. Приватность каждого — прямым текстом в колонке
«что покидает компьютер».

| | Уровень 1 · только скрипты | Уровень 2 · + локальная LLM | Уровень 3 · + облачная LLM |
|---|---|---|---|
| **Что получаешь** | Ngram Viewer, Река (температура по простым словарям), Big5-двойник | всё то же + Эмоциональная дуга и честная LLM-температура | то же, что уровень 2, только быстро |
| **Что нужно** | Python 3.10+ | + LM Studio и модель gemma-3-12b-it (~8 ГБ на диске, Mac/PC с 16+ ГБ RAM) | + аккаунт OpenRouter с парой долларов |
| **Время** (архив ~100 тыс. твоих сообщений) | **минуты** | ~0.5–1.5 сообщ/с → **сутки-трое**; чекпоинт: можно гонять ночами по частям; 10 тыс. сообщений — за вечер | 5–12 сообщ/с → **3–7 часов**; ~$2–4 за 100 тыс. (реальный прогон автора: 112 тыс. за $2.31) |
| **Что покидает компьютер** | **ничего** | **ничего** (модель крутится на твоей машине) | **твои собственные сообщения**, по одному, без реплик собеседников — уходят провайдеру модели через OpenRouter |
| **Команды** | шаги 1–4 ниже | + `python scripts/05_annotate_llm.py` и `python scripts/06_emo_arc.py` | + те же два шага с переменными `CHATRIVER_LLM_*` (см. шапку скрипта 05) |

Уровень можно повышать потом: начни с первого, дуга добавится, когда дозреешь.
Подробный разбор приватности — [`PRIVACY.md`](PRIVACY.md).

## Самый простой способ: отдай эту папку своему ИИ-агенту

Если у тебя есть Claude Code, ChatGPT (desktop с доступом к файлам / Codex CLI) или любой
агент, умеющий запускать команды, — просто скажи ему:

> Прочитай AGENT.md в этой папке и сделай всё по инструкции. Мой экспорт лежит в <путь>.

Агент покажет примеры, поможет с экспортом, установит зависимости, прогонит скрипты и
отдаст тебе готовые HTML-файлы. Инструкция для агента написана так, что он **не читает
твои сообщения** — только запускает готовые скрипты и смотрит на счётчики.

## Вручную

1. **Сделай полный экспорт Telegram** — пошаговая инструкция со всеми галочками:
   [`EXPORT.md`](EXPORT.md). Три главные вещи: экспорт есть только в настольном
   Telegram на движке tdesktop (на macOS это **Telegram Lite** из App Store или
   Telegram Desktop с telegram.org — в «обычном» маковском Telegram кнопки нет);
   у Private groups/channels сними галочку «Only my messages»; формат —
   **Machine-readable JSON**. На выходе — папка с файлом `result.json`.

2. Установи зависимости (Python 3.10+):
```bash
pip install -r requirements.txt
```

3. Подготовь данные (замени путь на свой):
```bash
python scripts/01_prepare.py "/path/to/DataExport/result.json"
```

4. Построй базовые артефакты:
```bash
python scripts/02_ngram.py && python scripts/03_river.py && python scripts/04_big5.py
```

Готово: открывай файлы из `out/` в браузере.

Для двойника Big5 сначала пройди тест на [bigfive-test.com](https://bigfive-test.com)
и впиши баллы в `my_big5.md` (скопируй из `templates/big5-results-template.md`).
Без него `04_big5.py` построит страницу только с корпусной половиной.

## Эмоциональная дуга (уровни 2 и 3)

Каждое твоё сообщение прогоняется через LLM и получает оценку эмоционального тона;
из оценок складывается дуга твоих лет — где было холодно, где теплело, где просело.

**Уровень 2 (локально):** поставь [LM Studio](https://lmstudio.ai), скачай в нём
gemma-3-12b-it, включи Local Server и запусти:

```bash
python scripts/05_annotate_llm.py
python scripts/06_emo_arc.py
```

Скрипт печатает скорость и ETA; чекпоинт после каждого ответа — прерывай и
перезапускай сколько угодно, прогресс не теряется.

**Уровень 3 (облако, быстро):** те же две команды, но перед ними — три переменные
окружения (`CHATRIVER_LLM_URL/MODEL/KEY`, разобрано в шапке скрипта). Помни, что
этим ты отправляешь свои сообщения провайдеру — уровень выбирается осознанно.

## Нет экспорта под рукой? Проверь на демо

```bash
python scripts/00_make_demo.py && python scripts/01_prepare.py demo/result.json
```

Дальше те же скрипты 02–06; для шага 05 на демо используй суррогатный флаг:
`python scripts/05_annotate_llm.py --synthetic` (без LLM). Именно так собраны
страницы в `examples/`.

## Приватность

Коротко: **всё локально**. Базовые скрипты не имеют сетевого кода; страницы
самодостаточны (данные зашиты внутрь HTML) и содержат ТОЛЬКО твои собственные
сообщения — реплики собеседников не попадают ни в какой выходной файл. Опциональный
LLM-шаг по умолчанию тоже локальный (LM Studio); облачный режим включается только
вручную и осознанно. Подробнее — `PRIVACY.md`.
Помни: готовые HTML содержат твои цитаты и имена чатов — не публикуй их бездумно.

## Ограничения честно

- Экспорт Telegram не содержит: секретные чаты, удалённые сообщения, контент публичных
  каналов, чаты с защитой контента. Это невосполнимо — учитывай в интерпретациях.
- Эмо-слой (шаги 5–6 и температура реки при его наличии): промпт валидирован автором
  на собственной ручной разметке — κ≈0.53, «умеренная согласованность». Это значит:
  агрегатным кривым по сотням сообщений в месяц верить можно, оценке отдельного
  сообщения — нельзя. Сарказм-метка вообще не валидирована. Промпт русскоязычный:
  для других языков модель сработает, но валидация не переносится.
- Без шага 5 «температура» реки — прозрачные мини-словари эмоций (русский),
  не валидированная психометрия.
- Big5-двойник — развлекательное сопоставление на N=1, не диагностика; в литературе
  соответствие языка и самоотчёта ограничено r ≈ 0.3–0.4.
