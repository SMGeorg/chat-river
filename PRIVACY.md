# Приватность

Главное одной таблицей — что покидает твой компьютер на каждом уровне обработки:

| Уровень | Что уходит наружу |
|---|---|
| 1 · только скрипты | **ничего** |
| 2 · + локальная LLM (LM Studio) | **ничего** — модель работает на твоей машине |
| 3 · + облачная LLM (OpenRouter) | **твои собственные сообщения**, по одному, без реплик собеседников |

Подробности:

- Базовые вычисления (шаги 1–4, 6) выполняются на твоём компьютере; в их коде нет
  ни одного сетевого вызова.
- В выходные HTML попадают ТОЛЬКО твои собственные сообщения (цитаты в подсказках) и
  агрегированные счётчики; реплики собеседников не выгружаются никуда.
- data/ и out/ остаются локально и внесены в .gitignore — случайно закоммитить их нельзя.
- Опциональный LLM-шаг (5) по умолчанию использует локальный LM Studio: твои сообщения
  идут на localhost и не покидают машину. Облачный режим (переменные CHATRIVER_LLM_*)
  отправляет провайдеру ТВОИ СОБСТВЕННЫЕ сообщения по одному, без реплик собеседников —
  включается только вручную; включая его, ты принимаешь это осознанно. Реплики других
  людей в любой режим шага 5 не попадают.
- Если тебе помогает ИИ-агент: инструкция AGENT.md запрещает ему читать твои сообщения;
  он видит только счётчики и статусы, а облачный режим шага 5 может предлагать только
  после явного предупреждения. Проверяй, что твой агент ей следует.
- Папка examples/ — полностью синтетические данные (вымышленные имена, сгенерированные
  тексты); ничего личного в репозитории нет.
- Готовые страницы содержат твои цитаты и имена чатов: делись ими осознанно.
